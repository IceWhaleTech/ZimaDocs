# Legacy Docs 2025 Archive

This directory preserves the `source/docs`, `source/faq`, and `source/knowledge` content retired by the v0.6 information architecture migration.

- The 27 Markdown files are historical records and are not part of the Hexo source tree.
- File bodies and Front Matter are preserved exactly as they existed before archival.
- `manifest.csv` records the original path, archive path, SHA-256 checksum, and final successor URL.
- Historical URL compatibility is provided only by `source/_redirects`; archived files must never be compiled or linked as canonical pages.
- Restore or reuse content only through an explicit editorial review. Do not move these directories back under `source/`.

Archived on 2026-08-24 as part of the v0.6 documentation information architecture and URL refactor.
