Visão geral do ZimaOS

Última atualização: 2026-08-27

Reunimos estes guias para o ajudar a ficar à vontade com o ZimaOS, quer tenha acabado de abrir a caixa, quer já o utilize há algum tempo.

Configuração e armazenamento

Comece aqui depois do primeiro arranque. Primeiro, trate das definições fundamentais.

  • Primeiros passos — defina o idioma, a rede e a conta
  • Visão geral das funcionalidades — explore o Data Station, a gestão de aplicações e as definições
  • Configuração do armazenamento — selecione as unidades certas para a sua utilização
  • Opções de RAID — consulte a referência detalhada de RAID
  • Caminhos de armazenamento das aplicações — escolha a unidade onde ficam os dados das aplicações

Sincronização e cópias de segurança

Depois da configuração inicial, importe os conteúdos e decida onde cada tipo de dados deve ficar.

  • Cópia de segurança do telemóvel — proteja automaticamente os dados do telemóvel
  • Cópia de segurança do computador — configure o acesso e as cópias agendadas do portátil
  • Ligar unidades na nuvem — importe dados dos principais serviços de nuvem
  • Migrar de outro NAS — siga o percurso recomendado a partir de Synology
  • Transferência manual de Synology — procedimento manual através de SMB
  • Mover dados entre unidades — utilize a ferramenta integrada quando uma unidade fica cheia
  • Cópia de segurança 3-2-1 — crie um plano que proteja todos os dados importantes
  • Cópia com Time Machine — proteja o Mac com o Time Machine

Acesso e partilha

Quando os dados estiverem organizados, disponibilize-os com segurança aos utilizadores e dispositivos certos.

  • Acesso remoto — ligue-se ao ZimaOS fora de casa
  • Transferir o ZimaClient — instale o cliente para navegar nos ficheiros
  • Partilha de ficheiros SMB — disponibilize ficheiros na rede local
  • Partilhar por ligação — envie ficheiros através de uma ligação
  • Samba com vários utilizadores — atribua níveis de acesso diferentes

Métodos de instalação

Escolha a forma de instalar o ZimaOS que melhor corresponde ao hardware e ao ambiente.

  • Instalar o ZimaOS — grave a imagem numa unidade USB e arranque o dispositivo
  • Instalar no Proxmox — utilize o ZimaOS numa máquina virtual
  • Migrar do CasaOS — migre a configuração existente
  • Obter o ID de rede — consulte o identificador único do dispositivo
  • Repor a palavra-passe — recupere o acesso à conta

Sistema

Mantenha o dispositivo estável e preparado para recuperar de uma falha.

  • Configuração de UPS — evite danos provocados por cortes inesperados
  • Recuperação do sistema — recupere o sistema quando algo corre mal
  • Instalação offline — implemente o sistema num ambiente isolado
  • Função de pesquisa — pesquise em todas as unidades

Próximo passo

Não precisa de aprender tudo de uma vez. Continue pelo caminho que corresponde ao que pretende fazer agora.

  • Comparar dispositivos: Visão geral do hardware — consulte as três linhas de produto
  • Executar aplicações: Visão geral da Loja de aplicações — servidores multimédia, aplicações autoalojadas e agentes de IA
  • Aprofundar: Visão geral de desenvolvimento — ZFS, RAID, redes e API do ZimaOS
