ハードウェア概要

最終更新日: 2026-08-27

Zima には、異なる利用者を想定した 3 つのハードウェア製品ラインがあります。このページでは、所有している端末の確認や、目的に合うモデルの選択ができます。

端末を比較

ZimaCube 2 ZimaBoard 2 ZimaBlade
おすすめ用途 プロ向け NAS、メディア制作、ローカル AI ホームサーバー、ネットワーク、実験 入門 NAS、初めての DIY 構築
CPU Intel i3-1215U / i5-1235U（Pro） Intel N150（4 コア、最大 3.6 GHz） Intel Celeron N3350（3760）/ 4 コア（7700）
メモリ 8 GB DDR5（最大 64 GB） 8 GB / 16 GB LPDDR5（オンボード） DDR3L SODIMM x1、最大 16 GB
ドライブベイ SATA x6 + M.2 NVMe x4 SATA 3.0 x2 + 32/64 GB eMMC SATA 3.0 x2
ネットワーク 2.5 GbE x2（Pro は 10 GbE も搭載） 2.5 GbE x2 1 GbE x1
Thunderbolt 全モデル TB4 x2 なし なし
PCIe PCIe 4.0 x16 + PCIe 3.0 x8 PCIe 3.0 x2 PCIe 2.0 x4 x1

端末をセットアップ

開封したばかりの場合は、端末に合ったクイックスタートから始めてください。

  • ZimaCube クイックスタート — 開封、配線、初回アクセスを行います
  • ZimaBoard の電源を入れる — 初回起動と基本設定を行います
  • ZimaBlade の電源を入れる — HDD スタンドと初回起動を設定します

ハードウェアの詳細

起動後は、以下のページでポート、拡張スロット、内部構造を確認できます。

  • ZimaCube ハードウェア詳細 — すべてのポートと接続部を確認します
  • ZimaBoard ハードウェアインターフェース — ピン配列とコネクターを確認します
  • ZimaCube PC 直接接続 — ZimaCube を PC に直接つなぎます
  • ZimaCube GPU 拡張 — 専用グラフィックカードを追加します
  • ZimaCube RAID SSD 拡張 — SSD キャッシュや高速ストレージを追加します
  • DIY ファンガイド — 冷却ファンを交換します

互換性

実際に検証した対応機器と機能をまとめています。

  • UPS 互換性リスト — 動作確認済みの UPS です
  • 対応ディスク形式 — 対応するファイルシステムです
  • 対応ネットワークアダプター（英語） — 動作確認済みの NIC です
  • Intel AX210 Wi-Fi — ZimaOS で AX210 を有効にします
  • AX210 Wi-Fi モジュール — ZimaBoard に AX210 を取り付けます
  • BIOS 設定 — BIOS を開いて調整します
  • Wake-on-LAN を有効化 — ZimaCube を遠隔起動します
  • ZimaBoard の Wake-on-LAN — ZimaBoard を遠隔起動します

サードパーティ OS

ZimaOS はプリインストールされていますが、ハードウェアはロックされていません。コミュニティでは Unraid、TrueNAS、OpenWrt なども利用されています。

  • Unraid を実行 — ZimaCube に Unraid を導入します
  • TrueNAS を実行 — ZimaCube に TrueNAS を導入します
  • ZimaBoard で Unraid を実行 — ZimaBoard に Unraid を導入します
  • OpenWrt を実行 — ZimaBoard をホームルーターにします
  • USB から OpenWrt を実行 — USB ドライブから OpenWrt を起動します
  • OpenWrt eMMC 起動 — 内蔵ストレージへ導入します
  • OMV をインストール — NAS 向けの OpenMediaVault を導入します
  • OMV を設定 — インストール後の基本設定です
  • Arch Linux をインストール — ZimaBoard 2 で Arch Linux を実行します
  • Ubuntu Server を設定 — 軽量なサーバー環境を作ります
  • サードパーティ OS ガイド — 汎用的な OS インストール手順です

次のステップ

ハードウェアが分かれば、その後の設定も選びやすくなります。

  • ZimaOS を設定：**ZimaOS 概要** — インストール、ストレージ、システム設定
  • アプリを実行：**App Store 概要** — メディアサーバー、自宅ホストアプリ、AI エージェント
