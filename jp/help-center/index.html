その他の概要

最終更新日: 2026-08-28

よく発生する問題と解決方法をここにまとめました。期待どおりに動作しない場合は、実際の症状に近い項目から確認してください。

トラブルシューティング

症状に合うガイドを選んでください。それぞれのページで解決方法を順番に説明します。

  • CMOS リセット — BIOS の既定値を復元します
  • RAID トラブルシューティング — RAID を作成できない場合の確認手順です
  • BIOS 更新方法 — ZimaCube の BIOS を更新します
  • メモリーテスト — メモリーを詳しく検査します
  • セルフテストガイド — 内蔵診断を実行します
  • 組み立てガイド — 分解と再組み立ての手順です
  • Thunderbolt 接続の問題 — 接続を確立できない場合の対処です
  • アカウント初期化の失敗 — 初期設定が完了しない場合に使用します
  • 工場出荷状態へ復元 — ZimaBoard をリセットします
  • BIOS アップグレード — ZimaBoard の BIOS を更新します
  • IP アドレスを確認 — ネットワーク上の端末を見つけます

リファレンス

  • プライバシーポリシー — データの取り扱いを確認します
  • Zima 端末で Unraid を実行（英語） — 各 Zima 端末への Unraid 導入方法です
