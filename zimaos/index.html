ZimaOS Overview

Last updated: 2026-08-28

I put these guides together to help you get comfortable with ZimaOS — whether you just opened the box or have been using it for a while.

Setup and Storage

Start here after your first boot. Three things to get right.

  • Get Started — language, network, and account setup
  • Features Overview — a walkthrough of Data Station, app management, and settings
  • Storage Setup — choose the right drives for your use case
  • RAID Options — detailed RAID configuration reference
  • App Storage Paths — set where your app data is stored

Sync and Backup

Once the basics are set, bring your content in and decide where everything lives.

  • Phone Backup — automatic photo and file backup from your phone
  • Computer Backup — Finder, Explorer, and scheduled backup for laptops
  • Connect Cloud Drives — pull data out of Google Drive, Dropbox, and OneDrive
  • Move from Another NAS — the recommended path from Synology
  • Synology Manual Transfer — step-by-step SMB manual
  • Move Data Between Drives — the built-in tool when a drive fills up
  • 3-2-1 Backup — the backup plan that protects it all
  • Time Machine Backup — back up your Mac to ZimaOS over the network

Access and Share

Once your data is in place, make it accessible.

  • Remote Access — reach your ZimaOS when you are away from home
  • Download ZimaClient — install the desktop app to browse files
  • SMB File Sharing — share files across your local network
  • Share via Link — generate a link to share files without an account
  • Samba Multi-User — per-user access control for Samba shares

Install Methods

Different ways to get ZimaOS running, depending on your setup.

  • Install ZimaOS — write the image to a USB drive and boot your device
  • Install on Proxmox — run ZimaOS as a virtual machine
  • Migrate from CasaOS — move your setup from CasaOS to ZimaOS
  • Get Network ID — find your device’s unique network identifier
  • Reset Password — recover or change your ZimaOS password

System

Keep your device running smoothly.

  • UPS Setup — protect against power outages
  • System Recovery — restore ZimaOS after a failure
  • Offline Installation — install ZimaOS without an internet connection
  • Search Function — find files across your NAS

Next

You do not need to learn everything at once. Take whichever path matches what you are working on.

  • Compare devices: Hardware Overview — ZimaCube, ZimaBoard, and ZimaBlade side by side
  • Run apps: App Store Overview — media servers, self-hosted apps, and AI agents
  • Go deeper: Dev Overview — ZFS, RAID, networking, and the ZimaOS API
