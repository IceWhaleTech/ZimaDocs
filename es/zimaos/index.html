Resumen de ZimaOS

Última actualización: 2026-08-28

Hemos reunido estas guías para que puedas familiarizarte con ZimaOS, tanto si acabas de abrir la caja como si llevas tiempo utilizándolo.

Configuración y almacenamiento

Empieza aquí después del primer arranque. Primero conviene dejar bien configurados los elementos básicos.

  • Primeros pasos — configura el idioma, la red y la cuenta
  • Resumen de funciones — conoce Data Station, la administración de aplicaciones y los ajustes
  • Configuración del almacenamiento — selecciona las unidades apropiadas para tu caso de uso
  • Opciones de RAID — consulta la referencia detallada de RAID
  • Rutas de almacenamiento de aplicaciones — decide en qué unidad se almacenan los datos de las aplicaciones

Sincronización y copias de seguridad

Cuando la base esté lista, incorpora tus contenidos y decide dónde vivirá cada cosa.

  • Copia de seguridad del teléfono — protege automáticamente las fotos y los archivos del teléfono
  • Copia de seguridad del ordenador — configura el acceso y las copias programadas del portátil
  • Conectar unidades en la nube — importa datos desde Google Drive, Dropbox y OneDrive
  • Migrar desde otro NAS — sigue la ruta recomendada desde Synology
  • Transferencia manual desde Synology — procedimiento manual mediante SMB
  • Mover datos entre unidades — utiliza la herramienta integrada cuando una unidad se llena
  • Copia de seguridad 3-2-1 — crea un plan que proteja todos tus datos importantes
  • Copia con Time Machine — protege tu Mac mediante Time Machine

Acceso y uso compartido

Cuando los datos estén en su sitio, hazlos accesibles de forma segura.

  • Acceso remoto — entra en ZimaOS cuando estés fuera de casa
  • Descargar ZimaClient — instala el cliente y navega por tus archivos
  • Archivos compartidos por SMB — comparte archivos dentro de la red local
  • Compartir mediante enlace — genera un enlace para compartir archivos
  • Samba multiusuario — asigna permisos diferentes a cada usuario

Métodos de instalación

Elige la forma de instalar ZimaOS que mejor se adapte a tu hardware y entorno.

  • Instalar ZimaOS — escribe la imagen en una unidad USB y arranca el dispositivo
  • Instalar en Proxmox — utiliza ZimaOS dentro de una máquina virtual
  • Migrar desde CasaOS — migra tu configuración existente
  • Obtener el ID de red — consulta el identificador único del dispositivo
  • Restablecer la contraseña — recupera el acceso a tu cuenta

Sistema

Mantén el dispositivo estable y preparado para recuperarse ante un fallo.

  • Configuración de UPS — evita daños por apagones inesperados
  • Recuperación del sistema — recupera el sistema cuando algo sale mal
  • Instalación sin conexión — despliega el sistema en un entorno aislado
  • Función de búsqueda — encuentra archivos en todas las unidades

Siguiente paso

No necesitas aprenderlo todo de una vez. Continúa por la ruta que corresponda a lo que quieres hacer ahora.

  • Comparar dispositivos: Resumen de hardware — consulta las tres líneas de producto
  • Ejecutar aplicaciones: Resumen de la tienda de apps — servidores multimedia, aplicaciones autoalojadas y agentes de IA
  • Profundizar: Resumen de desarrollo — ZFS, RAID, redes y API de ZimaOS
