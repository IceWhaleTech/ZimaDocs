ZimaOS V1.6.2

本次更新聚焦于三大关键领域：安全加固、系统稳定性提升以及硬件兼容性改善。

安全：

  1. 紧急修复了账户管理模块中的高危安全漏洞，进一步提升了管理员操作的安全性
  2. 紧急修复了文件服务中的高危安全漏洞，提高了文件访问与操作的安全性
  3. 修复了消息服务中的高危安全漏洞，增强了系统通信安全性
  4. SSH 现在默认禁用 root 用户的远程登录，降低了高权限账户的暴露风险
  5. SSH 增加了多项安全策略，以防暴力破解攻击
  6. NFS 服务现在默认关闭，减少了未授权访问的风险

新增：

  1. 为文件应用增加了深色模式
  2. 添加了对阿里云盘集成的支持
  3. 将 Linux 内核更新至 6.18.9
  4. 增加了对 NVIDIA 470 / 580 / Open Kernel Module、Intel Xe / Battlemage、Realtek RTW88 / RTL8127、Intel / MediaTek / AIC8800 无线设备以及 Cirrus Logic 音频设备的驱动支持，并新增了 NVIDIA 驱动自动检测与适配机制，可根据硬件自动匹配相应的驱动版本

修复：

  1. 修复了 OneDrive 密钥过期导致连接问题，恢复基本集成可用性，并优化了密钥更新机制
  2. 修复了 Collabora Server 应用阻止备份的问题，确保备份任务能够正常运行
  3. 修复了启动时多个 USB 存储设备可能被分配同一挂载点的问题
  4. 修复了 USB 挂载点冲突时生成传统 -device-name 后缀的问题
  5. 修复了使用相同序列号磁盘创建 RAID 阵列后，重启导致 RAID 降级的问题

优化：

  1. 优化了导入、迁移、加密、复制和剪切等高频文件操作流程
  2. 优化了云盘上传状态显示，让用户更清晰地了解当前进度、完成状态及失败原因

提示：

如果您遇到任何软件问题，欢迎加入我们的 Discord 社区，与超过 43,000 名 Zima 成员交流并获得支持！
https://zimaboard.com/discord
