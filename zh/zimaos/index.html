ZimaOS 概览

我们整理了这些指南，帮助你轻松上手 ZimaOS。无论你刚刚开箱设备，还是已经使用了一段时间，都可以从这里找到合适的入口。

设置与存储

首次启动后从这里开始。优先完成下面几项基础设置。

  • 开始使用 — 完成语言、网络和账户设置
  • 功能概览 — 浏览 Data Station、应用管理和系统设置
  • 存储设置 — 为你的使用场景选择合适的磁盘
  • RAID 选项 — 查看详细的 RAID 配置参考
  • 应用存储路径 — 设置应用数据保存在哪块磁盘上

同步与备份

基础设置完成后，将内容迁入 ZimaOS，并确定每类数据的存放位置。

  • 手机备份 — 自动备份手机中的照片和文件
  • 电脑备份 — 为笔记本电脑设置访问和定时备份
  • 连接云盘 — 从 Google Drive、Dropbox 和 OneDrive 导入数据
  • 从其他 NAS 迁移 — 从群晖迁移时推荐使用的流程
  • 群晖手动传输 — SMB 手动迁移的分步指南
  • 在磁盘之间迁移数据 — 磁盘空间不足时使用内置迁移工具
  • 3-2-1 备份 — 建立覆盖全部重要数据的备份方案
  • Time Machine 备份 — 将 Mac 通过网络备份到 ZimaOS

访问与共享

数据准备好后，让需要的人和设备能够安全访问。

  • 远程访问 — 离开家后仍可访问 ZimaOS
  • 下载 ZimaClient — 安装桌面客户端并浏览文件
  • SMB 文件共享 — 在局域网内共享文件
  • 通过链接共享 — 生成链接并将文件分享给其他人
  • Samba 多用户设置 — 为每位用户分配不同的共享访问权限

安装方式

根据你的硬件和部署环境，选择合适的 ZimaOS 安装方式。

  • 安装 ZimaOS — 将系统镜像写入 USB 设备并启动安装
  • 安装到 Proxmox — 将 ZimaOS 作为虚拟机运行
  • 从 CasaOS 迁移 — 把现有 CasaOS 环境迁移到 ZimaOS
  • 获取网络 ID — 查看设备唯一的网络标识符
  • 重置密码 — 找回或修改 ZimaOS 密码

系统

让设备保持稳定运行。

  • UPS 设置 — 防范突然断电
  • 系统恢复 — 在系统故障后恢复 ZimaOS
  • 离线安装 — 无网络环境下安装 ZimaOS
  • 搜索功能 — 跨存储空间快速查找文件

下一步

你不需要一次学完所有内容。根据当前要完成的事情选择下一条路径即可。

  • 比较设备：**硬件概览** — 对比三条产品线的硬件
  • 运行应用：**应用商店概览** — 媒体服务器、自托管应用与 AI 智能体
  • 深入探索：**开发者概览** — ZFS、RAID、网络与 ZimaOS API
