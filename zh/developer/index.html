开发者概览

如果你希望深入系统内部，这一部分就是为你准备的。存储系统、网络和 ZimaOS API 等高级用户与开发者需要的内容都集中在这里。

存储与文件系统

ZimaOS 原生支持 ZFS、RAID、NFS 和 iSCSI。可以从以下指南开始了解和配置这些存储能力。

  • ZFS 设置 — 创建和管理 ZFS 存储池
  • RAID 选项概览 — 根据使用场景选择合适的 RAID 级别
  • 创建 RAID 6 — 分步配置双重奇偶校验 RAID
  • RAID 重建 — 重装系统后恢复 RAID 阵列
  • NFS 文件共享 — 为 Linux 和 macOS 设置 NFS 共享
  • iSCSI 使用指南 — 使用 iSCSI 配置块级存储
  • iSCSI 设置 — 完整的 iSCSI 配置流程
  • Rsync 备份克隆 — 使用 rsync 克隆磁盘或数据集
  • 连接群晖 SMB — 通过 SMB 连接现有群晖设备
  • QTS 双向同步 — 与 QNAP 建立双向文件夹同步
  • 加密文件夹 — 在文件系统层保护敏感数据

网络与协议

正确的网络配置能让其他服务运行得更快、更稳定。

  • 网络配置 — 设置接口、路由与静态地址
  • 启用 SSH — 开启 SSH 并完成基础访问设置
  • SSH 高级设置 — 配置密钥认证、端口和安全加固
  • 网络传输速度 — 定位并修复网络瓶颈

开发

在 ZimaOS 之上构建自己的 Docker 应用、Python 脚本，或直接参与项目贡献。

  • Python 环境 — 配置 Python 脚本与自动化环境
  • 贡献指南 — 参与代码、文档和反馈贡献
  • 社区贡献 — 浏览用户提交的驱动与功能改进

应用商店开发

为 ZimaOS 家庭服务器构建 Docker 与 self-hosted 应用，维护 Homelab 应用目录，或为其他 NAS OS 环境发布兼容的应用商店。

  • 构建并发布应用 — 准备单个应用并提交到商店
  • 创建应用商店 — 从源文件构建兼容 v2 的商店
  • Docker Compose 与 x-casaos — 查询运行时和元数据字段
  • 应用商店 CI/CD — 自动化验证、构建制品和静态托管
  • 从 v1 迁移到 v2 — 在采用静态产物的同时保留兼容性
  • 开发者 FAQ — 应用 ID、多语言、托管、构建与兼容性

ZimaOS API

通过 API，可以从自己的代码中自动执行文件操作、用户管理和系统设置。

  • ZimaOS API 指南 — 认证、接口端点与集成示例
  • ZimaOS API 浏览器 — 在浏览器中实时尝试 API 调用
