商店

构建你自己的服务器。

从在任意 x86 设备上安装 ZimaOS，到运行应用，再到充分发挥 ZimaCube、ZimaBoard 和 ZimaBlade 的潜力，这里提供你所需的一切资料。

开始使用 浏览全部文档

完成初始设置。

首次启动后从这里开始。安装 ZimaOS、配置好存储，并让你能随时随地访问文件。

  • 将系统镜像写入 U 盘，启动设备并创建账户。这里也包括 Proxmox VE 和离线安装方式。

  • 选择 RAID 级别、添加硬盘，并决定应用数据的存放位置。单盘和 JBOD 配置同样适用。

  • 在局域网中通过 Finder 或文件资源管理器访问文件，也可以使用远程访问和分享链接随时随地连接。

设置指南

运行你的应用。

将设备变成媒体服务器、照片库或私有 AI 主机。既可从应用商店一键安装，也可使用自己的 Docker Compose。

  • 使用 Jellyfin、Plex 或 Emby，并在需要时启用 GPU 转码，让家中每一块屏幕都能访问你的媒体库。

  • Syncthing、Pi-hole、Paperless，以及数百款其他应用。可从应用商店安装，也可使用自己的 Docker Compose。

  • 在自己的硬件上运行 DeepSeek 和其他模型；需要更强性能时，还可以添加 GPU。

浏览应用场景

探索高级功能。

RAID、ZFS、iSCSI、网络与 ZimaOS API，适合默认设置已无法满足需求的场景。

  • 配置 ZFS 存储池、RAID 6、加密文件夹和 iSCSI 目标，并了解系统重装后的阵列重建。

  • 打开终端、设置静态地址、优化传输速度，并通过 SMB 连接另一台 NAS。

  • 发布 Docker 应用、调用 ZimaOS OpenAPI，或向文档项目提交拉取请求。
