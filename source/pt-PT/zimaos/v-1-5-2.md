## Novo
Adicionado suporte para dispositivos UPS via protocolo USB
Adicionada pré-visualização de Live Photo e reprodução automática para imagens HEIC em Ficheiros
Adicionada função de limpeza de cache de aplicações com um clique
Adicionado editor Markdown integrado
## Corrigido
Corrigida a exibição anormal de “ZimaOS-HD” em Ficheiros quando a unidade USB é usada como disco do sistema
Corrigido o zima-storage que não abria em Backup ao arrancar a partir de uma unidade USB
Corrigido o problema em que dispositivos de armazenamento não eram exibidos em Ficheiros devido a falha na análise do tipo de disco
Corrigidas anormalidades de exibição quando os caminhos dos pontos de montagem contêm espaços
Corrigido o cálculo anormal de tamanho ao migrar diretórios que contêm espaços
Corrigidos conflitos de nomes de projetos ao importar projetos usando docker-cli
Corrigida a instabilidade que causava a terminação inesperada do serviço avahi-daemon
Corrigido um bug crítico que listava incorretamente partições mmcblkboot como dispositivos selecionáveis na criação de armazenamento (estas são partições de arranque reservadas pelo sistema e nunca devem ser formatadas)
Corrigido o comportamento impreciso de “Ignorar” em Ficheiros durante a resolução de conflitos ao cortar/colar ficheiros
Corrigida a falta de suporte para a página de código CP850 no Samba (causando nomes de ficheiros ilegíveis em clientes Windows)
## Otimizado
Melhoradas as mensagens de aviso padrão após importar contentores via docker run
Otimizada a lógica do Índice de Armazenamento Local
Otimizada a interface inicial do módulo de backup e a interface de gestão de tarefas
Refinadas as descrições das políticas de backup para maior precisão e clareza
A escala do widget de rede agora ajusta-se dinamicamente
Otimizada a lógica de recomendação da loja de aplicativos
Expandido o intervalo de fontes de backup selecionáveis
Refinada a redação das estratégias de backup para melhor legibilidade
