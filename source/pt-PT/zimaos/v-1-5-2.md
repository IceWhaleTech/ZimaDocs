## Novidades
Adicionado suporte para dispositivos UPS através do protocolo USB
Adicionada pré-visualização de Live Photos e reprodução automática para imagens HEIC no Files
Adicionada função de limpeza de cache de aplicações com um clique
Adicionado editor Markdown integrado
## Corrigido
Corrigida a exibição anómala de “ZimaOS-HD” no Files quando uma unidade USB é usada como disco do sistema
Corrigido o problema do zima-storage não abrir no Backup ao arrancar a partir de uma unidade USB
Corrigido o problema em que dispositivos de armazenamento não eram mostrados no Files devido a falha na análise do tipo de disco
Corrigidas anomalias de exibição quando os caminhos dos pontos de montagem contêm espaços
Corrigido o cálculo anómalo de tamanho ao migrar diretórios que contêm espaços
Corrigidos conflitos de nomes de projetos ao importar projetos usando docker-cli
Corrigido o problema de estabilidade que causava a terminação inesperada do serviço avahi-daemon
Corrigido um bug crítico que listava incorretamente partições mmcblkboot como dispositivos selecionáveis na criação de armazenamento (estas são partições de arranque reservadas pelo sistema e nunca devem ser formatadas)
Corrigido o comportamento impreciso de “Ignorar” no Files durante a resolução de conflitos ao cortar/colar ficheiros
Corrigida a falta de suporte para a página de código CP850 no Samba (que causava nomes de ficheiros ilegíveis em clientes Windows)
## Otimizado
Melhoradas as mensagens de prompt padrão após importar contentores via docker run
Otimizada a lógica do índice LocalStorage
Otimizada a interface inicial do módulo de backup e a interface de gestão de tarefas
Refinadas as descrições das políticas de backup para maior precisão e clareza
A escala do widget de rede agora ajusta-se dinamicamente
Otimizada a lógica de recomendação da loja de aplicativos
Ampliada a gama de fontes de backup selecionáveis
Refinada a redação da estratégia de backup para melhor legibilidade
