**Photos 自 ZimaOS 1.8 起可用。**

Photos 天生就能接纳你拍摄的一切，从口袋里的手机到相机卡里的 RAW 文件。本页列出哪些内容会进入照片库，以及每种格式入库后的表现。

## 支持如何工作

一个文件在 Photos 中可能发生三件事，而且它们不一定同时发生：

- **索引。** 文件被收录进照片库。
- **缩略图。** 为图库生成预览图。
- **元数据。** 读取并显示相机、镜头和设置。

一种格式可能已入库，而缩略图取决于文件本身。RAW 是主要例子：相机内嵌 JPEG 预览的文件能快速生成缩略图，而没有内嵌预览的文件则需要解码。两者最终都带着元数据进入照片库。

## 图片格式

| 格式家族 | 索引 | 缩略图 | 元数据 |
|---|---|---|---|
| JPEG（.jpg、.jpeg、.jfif、.mpo） | 是 | 直接提供或缩放 | 标准字段加厂商标签 |
| HEIC、HEIF、AVIF | 是 | 内置提取器，避免完整解码 | 是，含 Live Photo 数据 |
| PNG、WebP、GIF、BMP、ICO | 是 | 通用管线 | 基本字段 |
| TIFF（.tif、.tiff） | 是 | 优先使用内嵌预览 | 是 |
| 专业容器（PSD、PSB、JPEG XL、JPEG 2000、EXR） | 是 | 通用管线 | 是 |

标准元数据字段为：相机、镜头、焦距、光圈、曝光时间、ISO、GPS、方向和拍摄日期。对于常见手机与相机品牌，MakerNote 和私有 XMP 等厂商元数据也会被读取。

## RAW 格式

根据相机内嵌的内容，RAW 文件走三种缩略图策略之一：

| 分组 | 格式 | 缩略图行为 |
|---|---|---|
| 内嵌预览优先 | ARW、TIFF | Photos 直接读取相机内嵌的 JPEG 预览，不解码传感器图像。 |
| 有预览时使用 | CR2、CR3、CRW、DNG、NEF、NRW、ORF、ORI、PEF、RW2、SR2、SRF 等 | 内嵌预览足够大时直接使用；否则 Photos 解码 RAW。 |
| 依赖解码器 | 3FR、DCR、ERF、IIQ、KDC、MEF、MOS、MRW、RAF、RWL、SRW | 这类文件极少带可用预览。缩略图靠解码生成，取决于解码器支持。 |
| 原生缩略图 | X3F | Photos 直接读取相机内置的 RGB 缩略图。 |

如果某种格式既没有内嵌预览，也没有解码器支持，文件仍会被索引、元数据仍会保留，只是缩略图不可用。

## 视频元数据

视频文件走独立的元数据路径。QuickTime 和 ISO-BMFF 文件（MOV、MP4）、AVI 和 Matroska（MKV）都会被解析，因此视频元数据与照片并列显示。
