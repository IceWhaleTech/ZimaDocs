## Nuevo
Se agregó soporte para dispositivos UPS mediante protocolo USB
Se agregó vista previa de Live Photo y reproducción automática para imágenes HEIC en Archivos
Se agregó función de limpieza de caché de aplicaciones con un clic
Se agregó editor Markdown integrado
## Corregido
Se corrigió la visualización anormal de “ZimaOS-HD” en Archivos cuando se usa una unidad USB como disco del sistema
Se corrigió que zima-storage no se abriera en Copia de seguridad al arrancar desde una unidad USB
Se corrigió el problema de que los dispositivos de almacenamiento no se mostraban en Archivos debido a un fallo al analizar el tipo de disco
Se corrigieron anomalías de visualización cuando las rutas de puntos de montaje contienen espacios
Se corrigió el cálculo anormal de tamaño al migrar directorios que contienen espacios
Se corrigieron conflictos de nombres de proyectos al importar proyectos usando docker-cli
Se corrigió un problema de estabilidad que causaba la terminación inesperada del servicio avahi-daemon
Se corrigió un error crítico que listaba incorrectamente las particiones mmcblkboot como dispositivos seleccionables en la creación de almacenamiento (estas son particiones de arranque reservadas del sistema y no deben formatearse nunca)
Se corrigió el comportamiento inexacto de "Omitir" en Archivos durante la resolución de conflictos al cortar/pegar archivos
Se corrigió la falta de soporte de la página de códigos CP850 en Samba (causando nombres de archivo corruptos en clientes Windows)
## Optimizado
Se mejoraron los mensajes predeterminados después de importar contenedores mediante docker run
Se optimizó la lógica del índice de LocalStorage
Se optimizaron la interfaz inicial del módulo de copia de seguridad y la interfaz de gestión de tareas
Se refinaron las descripciones de las políticas de copia de seguridad para mayor precisión y claridad
La escala del widget de red ahora se ajusta dinámicamente
Se optimizó la lógica de recomendación de la tienda de aplicaciones
Se amplió el rango de fuentes de copia de seguridad seleccionables
Se refinó la redacción de la estrategia de copia de seguridad para mejor legibilidad
