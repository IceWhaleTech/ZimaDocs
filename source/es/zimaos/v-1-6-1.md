Esta versión pone la personalización en el centro.

ZimaOS ahora se siente más tuyo — con visuales de dispositivo personalizados, diseños de almacenamiento, e incluso la experiencia de inicio de sesión.

También hemos mejorado la fiabilidad del almacenamiento con una mejor gestión de USB y un mecanismo de recuperación RAID más robusto, junto con mejoras de estabilidad en todo el sistema.
![información de la versión zimaos 1.6.0](https://manage.icewhale.io/api/static/docs/1785825578596_image.png)

## Nuevo:
1. Se agregó visualización personalizable para dispositivos de almacenamiento
2. Se agregó gestión de dispositivos de almacenamiento clase USB
3. Se agregó un mecanismo de guardado fiable para metadatos RAID, que admite la reidentificación y montaje automáticos del array original después de reinstalar el sistema o reemplazar el dispositivo
4. Se agregó visualización personalizable para imágenes de dispositivo y fondo de pantalla de inicio de sesión
## Corregido:
1. Se corrigió el problema de restricción de extracción en el módulo mod_management
2. Se corrigió el problema de restricción de conexión cuando SMB actúa como cliente
3. Se corrigió el problema de que SMB no "omitía carpetas sin permisos de compartición" como se esperaba
4. Se corrigió el problema de que los discos no pudieran entrar en suspensión normal debido a despertares intermitentes por el servicio smartd
5. Se corrigió el fallo de inicio de Docker causado por una interfaz de red docker0 anómala
6. Se corrigió el fallo de inicio del servicio Files debido a tablas de datos faltantes o estructura de tabla anómala
7. Se corrigió el problema de que el almacenamiento apareciera como ausente debido a la presencia de discos tipo vfat
8. Se corrigió la visualización inexacta de la Papelera de reciclaje
## Optimizado:
1. Se optimizó la visualización de información de tarjeta de red
2. Se optimizó la visualización de la página de configuración
3. Se optimizó el manejo de la lista de solicitudes en ZimaOS cuando no se está autenticado
4. Se optimizó el texto de aviso de error cuando falla la extracción de aplicaciones
5. Se ajustó el orden de visualización de la séptima unidad en dispositivos oficiales ZimaCube
6. Se optimizó la lógica de habilitación de dispositivos USB; ahora admite seleccionar un punto de montaje al habilitarlo, mejorando la flexibilidad.
