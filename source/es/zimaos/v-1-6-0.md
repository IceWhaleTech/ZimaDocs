Esta versión pone la personalización en el centro.

ZimaOS ahora se siente más tuyo — con visuales de dispositivo personalizados, diseños de almacenamiento, e incluso la experiencia de inicio de sesión.

También hemos mejorado la fiabilidad del almacenamiento con una mejor gestión de USB y un mecanismo de recuperación RAID más robusto, junto con mejoras de estabilidad en todo el sistema.
![información de versión zimaos 1.6.0](https://manage.icewhale.io/api/static/docs/1785825578596_image.png)

## Nuevo:
1. Se añadió visualización personalizable para dispositivos de almacenamiento
2. Se añadió gestión de dispositivos de almacenamiento clase USB
3. Se añadió mecanismo de guardado fiable para metadatos RAID, soportando reidentificación y montaje automáticos del arreglo original después de reinstalar el sistema o reemplazar el dispositivo
4. Se añadió visualización personalizable para imágenes de dispositivo y fondo de pantalla de inicio de sesión
## Corregido:
1. Se corrigió el problema de restricción de extracción en el módulo mod_management
2. Se corrigió el problema de restricción de conexión cuando SMB actúa como cliente
3. Se corrigió el problema donde SMB no "omitía carpetas sin permisos de uso compartido" como se esperaba
4. Se corrigió el problema donde los discos no podían entrar en suspensión normal debido a activaciones intermitentes por el servicio smartd
5. Se corrigió el problema de inicio fallido de Docker causado por una interfaz de red docker0 anormal
6. Se corrigió el problema de inicio fallido del servicio Files debido a tablas de datos faltantes o estructura de tabla anormal
7. Se corrigió el problema donde el almacenamiento aparecía como faltante debido a la presencia de discos tipo vfat
8. Se corrigió la visualización inexacta de la Papelera de reciclaje
## Optimizado:
1. Se optimizó la visualización de información de tarjetas de red
2. Se optimizó la visualización de la página de configuración
3. Se optimizó el manejo de la lista de solicitudes en ZimaOS cuando no se ha iniciado sesión
4. Se optimizó el texto de aviso de error cuando falla la extracción de aplicaciones
5. Se ajustó el orden de visualización de la séptima unidad en dispositivos ZimaCube oficiales
6. Se optimizó la lógica de habilitación de dispositivos USB; ahora soporta seleccionar un punto de montaje al habilitar, mejorando la flexibilidad.
