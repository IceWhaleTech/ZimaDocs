Esta actualización se centra en tres áreas clave: endurecimiento de la seguridad, estabilidad del sistema y mejora de la compatibilidad de hardware.
![Notas de lanzamiento de ZimaOS V1.6.2: seguridad, estabilidad y compatibilidad](https://manage.icewhale.io/api/static/docs/1785827168754_image.png)

## Seguridad:
1. Se corrigió urgentemente un problema de seguridad de alto riesgo en el módulo de gestión de cuentas, mejorando aún más la seguridad de las operaciones de administrador
2. Se corrigió urgentemente un problema de seguridad de alto riesgo en el servicio de archivos, mejorando la seguridad del acceso y las operaciones de archivos
3. Se corrigió un problema de seguridad de alto riesgo en el servicio de mensajería, mejorando la seguridad de la comunicación del sistema
4. SSH ahora desactiva el inicio de sesión remoto para el usuario root por defecto, reduciendo el riesgo de exposición de cuentas de alto privilegio
5. SSH ha añadido varias políticas de seguridad para prevenir ataques de fuerza bruta
6. El servicio NFS ahora está deshabilitado por defecto, reduciendo el riesgo de acceso no autorizado
## Nuevo:
1. Se añadió el modo oscuro para la aplicación Archivos
2. Se añadió soporte de integración con Alibaba Cloud Drive
3. Se actualizó el kernel de Linux a 6.18.9
4. Se añadió soporte de controladores para NVIDIA 470 / 580 / Open Kernel Module, Intel Xe / Battlemage, dispositivos inalámbricos Realtek RTW88 / RTL8127, Intel / MediaTek / AIC8800, y dispositivos de audio Cirrus Logic, y se añadió un mecanismo de detección y adaptación automática de controladores NVIDIA que coincide automáticamente con la versión adecuada del controlador según el hardware
## Corregido:
1. Se corrigió el problema de caducidad de la clave de OneDrive que causaba problemas de conexión, restaurando la disponibilidad básica de integración y optimizando el mecanismo de actualización de claves
2. Se corrigió un problema donde la aplicación Collabora Server bloqueaba las copias de seguridad, asegurando que las tareas de respaldo puedan ejecutarse correctamente
3. Se corrigió un problema donde múltiples dispositivos de almacenamiento USB podían recibir el mismo punto de montaje al inicio
4. Se corrigió un problema donde se generaban sufijos heredados de nombres de dispositivo cuando los puntos de montaje USB entraban en conflicto
5. Se corrigió la degradación de RAID después de reiniciar cuando se creaba una matriz RAID a partir de discos con el mismo número de serie
## Optimizado:
1. Se optimizaron los flujos de trabajo de operaciones de archivos de alta frecuencia como importación, migración, cifrado, copia y corte
2. Se optimizó la visualización del estado de subida de la nube, haciéndolo más claro para que los usuarios comprendan el progreso actual, el estado de finalización y las razones de fallo
