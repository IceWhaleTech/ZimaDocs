## Nuevo
Se añadió la función de carpetas cifradas (esta función está actualmente en fase de pruebas — por favor, haz una copia de seguridad de tus datos antes de usarla)
Se mejoró la gestión SMB: se añadió la función "Pausar uso compartido" — después de pausar, permanece en la lista y se puede reactivar en cualquier momento
Se añadió el botón de Almacenamiento en la barra lateral izquierda de Archivos para facilitar la gestión del almacenamiento montado
Archivos ahora admite conectarse a recursos compartidos Samba a través de IPv6 y nombres de dominio
## Corregido
Se corrigió una omisión de autenticación mediante el manejo de nombres de usuario a nivel del sistema
Se corrigió una redirección abierta en el parámetro de redirección de la página de inicio de sesión
Se corrigió el problema donde los procesos de reparación y expansión RAID no podían seleccionar discos correctamente
Se corrigió el problema donde los usuarios Miembro no podían crear nombres de usuario que contuvieran "elif"
Se corrigió el fallo de análisis en Red cuando una sola NIC tiene múltiples nombres lógicos
Se corrigió la imposibilidad de descargar archivos que contienen comas (,) en Archivos
Se corrigió el problema donde cancelar un recurso compartido SMB en una carpeta también cancelaba involuntariamente los recursos compartidos en sus subcarpetas
Se corrigió el fallo de vista previa de algunos archivos HEIC en Archivos
Se corrigieron problemas cuando los directorios de copia de seguridad contienen archivos socket o pipe
Se corrigió el fallo de montaje automático para registros de base de datos RAID almacenados como "BTRFS" en mayúsculas
Se corrigió la indisponibilidad de la Papelera cuando el disco del sistema está lleno
Se corrigió el problema donde vaciar la Papelera en BTRFS no reclamaba inmediatamente el espacio disponible
Se corrigió la imposibilidad de seleccionar carpetas compartidas después de crear un Miembro en Configuración
Se corrigió el montaje innecesario de particiones adicionales en discos de sistema tipo USB
Se corrigió el problema donde la creación de copias de seguridad tenía éxito pero aún así se mostraba un mensaje de error
## Optimizado
Se optimizó la página de gestión de almacenamiento
Se mejoraron los mensajes de error y avisos para operaciones de copia de seguridad
Se optimizó la visualización de la lista de archivos en Archivos: se eliminó el límite anterior de 10,000 archivos para navegar, ahora soporta una navegación fluida de un número mucho mayor de archivos
Se optimizó la lógica de manejo de errores al modificar el nombre del dispositivo
