## Nuevo
Se agregó soporte para el controlador de la tarjeta de red Realtek r8152
Se agregó soporte de controladores para las GPU de la serie Intel Battlemage
## Corregido
Se corrigió el fallo de inicio del UPS
Se corrigió la visualización anormal de ciertos datos de copia de seguridad
Se corrigió el problema por el cual no se podía cambiar el avatar
Se corrigió el problema de la ruta de configuración predeterminada de Midnight Commander
Se corrigió el problema que impedía abrir BTOP en algunos dispositivos
Se corrigió el problema por el cual ciertas tarjetas gráficas NVIDIA no se podían seleccionar en la configuración de la aplicación
## Optimizado
Se optimizó la lógica de visualización de la sección de recomendaciones de la App Store
Se optimizó la configuración del servicio Avahi para reducir la probabilidad de ser terminado por otras aplicaciones
Se optimizó la lógica de autorización: se agregó control de tiempo de espera, se agregaron solicitudes de respaldo IPv4 y se mejoró la disponibilidad de autorización
Se corrigió el problema de pantalla blanca al abrir ventanas emergentes en Configuración
## Consejos
