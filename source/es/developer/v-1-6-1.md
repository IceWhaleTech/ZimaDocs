## Corregido:
1. Se corrigió el problema por el cual los dispositivos USB no se montaban automáticamente después de una actualización.
2. Se corrigió el problema por el cual las tareas de respaldo aún respaldaban en el punto de montaje del sistema después de que se perdiera dicho punto de montaje.
3. Se corrigió el problema por el cual los módulos mod no iniciaban los servicios según la política de servicios después de un reinicio.
4. Se corrigió el problema por el cual el nombre del punto de montaje no coincidía con el nombre real del dispositivo cuando el nombre del dispositivo contenía espacios.
## Optimizado:
1. Se optimizó la lógica de visualización de la bahía de discos cuando un dispositivo de terceros tiene demasiados discos.
2. Se añadieron traducciones faltantes para algunas funciones de visualización de almacenamiento.
