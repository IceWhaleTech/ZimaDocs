_Última actualización: 31 de agosto de 2026_

Este aviso de privacidad describe cómo **IceWhale Technology Limited** ("Compañía", "nosotros") procesa tu información cuando utilizas ZimaOS y los servicios relacionados.

Si tienes preguntas o no estás de acuerdo con estas prácticas, interrumpe el uso y contáctanos en **support@icewhale.org**.

Las declaraciones generales de esta política se aplican a las funciones principales de ZimaOS. Las secciones específicas de cada integración se aplican cuando habilitas dichas integraciones.

---

## Resumen

| Aspecto de Privacidad | Nuestro Compromiso |
|---|---|
| Recopilación de datos personales | **No** recopilamos, almacenamos ni analizamos tu información personal |
| Información sensible | **No** procesamos ningún dato personal sensible |
| Almacenamiento de datos | **No** almacenamos tus datos en ninguna forma |
| Compartición / venta de datos | **No** vendemos datos de usuarios ni participamos en actividades de intermediación de datos |
| Información que recibimos | Información del dispositivo y datos cifrados — utilizados solo para prestar servicios |

## ¿Qué Información Recopila ZimaOS?

Solo recibimos la **información de tu dispositivo y datos cifrados** para prestar los Servicios. **No** recopilamos, almacenamos, utilizamos ni analizamos tu información o datos personales.

La siguiente tabla describe las categorías de datos comunes y si las recopilamos:

| Categoría | Ejemplos | ¿Recopilado? |
|---|---|---|
| Identificadores | Nombre, alias, dirección postal, teléfono, dirección IP, correo electrónico, nombre de cuenta | No |
| Registros personales (estatuto de California) | Nombre, información de contacto, educación, empleo, información financiera | No |
| Características protegidas | Género, fecha de nacimiento | No |
| Información comercial | Transacciones, historial de compras, detalles de pago | No |
| Información biométrica | Huellas dactilares, huellas de voz | No |
| Actividad en Internet / red | Historial de navegación, historial de búsqueda, comportamiento en línea, interacciones | No |
| Datos de geolocalización | Ubicación del dispositivo | No |
| Audio, visual o similar | Imágenes, grabaciones, llamadas de video/audio | No |
| Profesional / empleo | Cargo, historial laboral, cualificaciones profesionales | No |
| Información educativa | Expedientes estudiantiles, información de directorio | No |
| Inferencias de otros datos | Perfiles de usuario, resúmenes de preferencias | No |
| Información personal sensible | — | No |

## Servicios de API de Google

Esta sección se aplica únicamente cuando decides conectar un servicio de Google a Zima Agent.

### Gmail

Con tu autorización, Zima utiliza el permiso mínimo necesario `gmail.modify` para buscar y leer correos electrónicos y archivos adjuntos pertinentes, proporcionar la asistencia de redacción solicitada y crear o actualizar borradores. Solo se accede a los datos de Gmail cuando solicitas estas funciones y no se utilizan para fines no relacionados.

Los mensajes, metadatos y archivos adjuntos de Gmail se procesan en tu dispositivo Zima o NAS autogestionado y no pasan por servidores operados por IceWhale ni se almacenan en ellos. Los servidores de IceWhale solo facilitan la autorización de Google OAuth y la renovación de tokens.

Cuando solicitas asistencia de IA, el contenido necesario de Gmail puede enviarse directamente desde tu dispositivo a la API de OpenAI configurada, sin pasar por los servidores de IceWhale. No se utiliza para entrenar ni mejorar modelos de IA generalizados.

Las credenciales de OAuth y el contenido de Gmail guardado en conversaciones, archivos adjuntos o archivos del espacio de trabajo permanecen en tu dispositivo. Las credenciales se conservan hasta que desconectas Gmail, restableces la aplicación o desinstalas Zima Agent. Puedes eliminar los datos locales de Gmail borrando las conversaciones, los archivos o los datos de la aplicación relacionados. Desconectar Gmail no elimina los mensajes de Gmail ni las copias que ya estén guardadas en tu dispositivo o en copias de seguridad.

No vendemos datos de usuarios de Google ni los compartimos con fines publicitarios. El acceso humano se limita al soporte que solicites, las investigaciones de seguridad o los requisitos legales. Nuestro uso de los datos de Google cumple la [Política de Datos de Usuario de los Servicios de API de Google](https://developers.google.com/terms/api-services-user-data-policy), incluidos los requisitos de Uso Limitado.

## ¿Cómo Mantenemos Segura Tu Información?

**No almacenamos tus datos, a diferencia de otros.** Tu seguridad y privacidad son nuestras máximas prioridades — nunca almacenamos tu información.

A diferencia de muchas empresas de Internet que recopilan y analizan grandes cantidades de datos de usuarios, operamos bajo un principio fundamentalmente diferente: **transparencia y respeto por tu privacidad**. No recopilamos, guardamos, utilizamos ni analizamos tus identificadores, información de ubicación ni ningún otro dato personal identificable.

Como no almacenamos datos, **no hay procesamiento de datos** que proteger. Puedes usar nuestros servicios con la confianza de que tu privacidad está protegida por diseño.

---

## ¿Se Compartirá Mi Información Con Alguien?

Compartimos solo la **información de tu dispositivo y datos cifrados** con proveedores de servicios — lo mínimo necesario para ofrecer servicios digitales efectivos. **Nunca** almacenamos, analizamos ni vendemos tu información personal.

IceWhale Technology Limited nunca participará en ninguna actividad comercial que implique la venta de datos de usuarios.

---

## ¿Puedo Revisar, Actualizar o Eliminar Mis Datos?

Dado que no almacenamos ni analizamos ninguno de tus datos, **no hay datos disponibles** para revisión o eliminación. Nuestra arquitectura sin almacenamiento significa que no hay nada que acceder, modificar o eliminar.
