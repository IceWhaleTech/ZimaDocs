よく発生する問題と解決方法をここにまとめました。期待どおりに動作しない場合は、実際の症状に近い項目から確認してください。

## トラブルシューティング

症状に合うガイドを選んでください。それぞれのページで解決方法を順番に説明します。

- **[CMOS リセット](./resets-cmos "起動できないときに CMOS をリセットして BIOS の初期値を戻す")** — BIOS の既定値を復元します
- **[RAID トラブルシューティング](./raid-troubleshooting "RAID 作成時によくあるエラーを解決する")** — RAID を作成できない場合の確認手順です
- **[BIOS 更新方法](./zimacube-bios-update-method "ZimaCube に最新 BIOS を書き込む")** — ZimaCube の BIOS を更新します
- **[メモリーテスト](./memory-test-tutorial "Zima 端末で完全なメモリー診断を実行する")** — メモリーを詳しく検査します
- **[セルフテストガイド](/docs/help-center/troubleshooting-self-test-guide "ZimaCube の内蔵ハードウェア診断を実行する")** — 内蔵診断を実行します
- **[組み立てガイド](./assembly-guide "ZimaCube を分解し、再度組み立てる")** — 分解と再組み立ての手順です
- **[Thunderbolt 接続の問題](./thunderbolt-connection-problem "ZimaCube の Thunderbolt 接続を修復する")** — 接続を確立できない場合の対処です
- **[アカウント初期化の失敗](./account-initialization-failed "ZimaOS のアカウント設定が止まる問題を解決する")** — 初期設定が完了しない場合に使用します
- **[工場出荷状態へ復元](./restore-factory-settings "ZimaBoard を工場出荷時の設定へ戻す")** — ZimaBoard をリセットします
- **[BIOS アップグレード](./bios-upgrade "ZimaBoard のマザーボード BIOS を更新する")** — ZimaBoard の BIOS を更新します
- **[IP アドレスを確認](./find-ip-address "接続できないときに端末の IP アドレスを探す")** — ネットワーク上の端末を見つけます

## リファレンス

- **[プライバシーポリシー](./privacy-policy "ZimaOS におけるデータと接続の取り扱いを見る")** — データの取り扱いを確認します
